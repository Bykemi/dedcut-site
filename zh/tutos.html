教程

一步一步学会 DedCut

为 DedCut 每个空间准备的简短易懂的指南。选择一个分类，或搜索你想做的事。

快速上手

安装 DedCut，了解最基本的用法。

  1. 在本网站点击“下载”：DedCut-Installation.exe 文件会保存到“下载”文件夹。
  2. 打开它。如果 Windows 显示“Windows 已保护你的电脑”，点击“更多信息”，再点“仍要运行”（DedCut 是新软件，Windows 还不认识它）。
  3. 安装只需几秒，不需要账号，也不需要管理员权限。
  4. DedCut 会在主页打开：可以开始了。

小提示 之后会自动更新：新版本准备好时 DedCut 会提醒你。

本教程的直达链接
  1. 在主页选择你想做的事，或用窗口最上方的按钮切换空间。
  2. 剪辑：剪辑视频（剪切、文字、特效、音乐、字幕、导出）。
  3. 录制：录制屏幕、游戏、摄像头和麦克风。
  4. 直播：在一个或多个平台上直播。
  5. 图像：做封面、修照片、画画。
  6. 音乐：做音乐，从鼓点到导出。

小提示 各空间相互连通：歌曲或图片一键就能送到剪辑。

本教程的直达链接
  1. Ctrl+Z 撤销上一步，Ctrl+Y 重做。想撤销多少次都可以。
  2. Ctrl+S 保存项目。DedCut 也会自动保存，什么都不会丢。
  3. 右上角的键盘按钮显示所有快捷键，还可以修改。
  4. 菜单（左上角）可以新建、打开、保存项目，打开设置，重新播放引导。
  5. 你可以移动面板，把时间线放在上方或下方，还能把面板拆成独立窗口。

小提示 DedCut 支持 9 种语言：在设置的“语言”中选择。

本教程的直达链接

视频剪辑

剪切，添加文字、特效和音乐，然后导出。

  1. 打开 剪辑 空间，再打开左侧的 媒体 标签。
  2. 从 Windows 文件资源管理器拖入视频、照片和声音，或点击区域进行选择。
  3. 再把每个素材拖到下方的时间线上：视频就在这里拼起来。
  4. 按 空格 播放或暂停预览。

小提示 4K 大视频？DedCut 会自动生成轻量副本，让预览保持流畅；导出时仍保留原始画质。

本教程的直达链接
  1. 把播放头（竖线）放到你想要的位置。
  2. 点击时间线上方的剪刀，或按 S：片段被分成两段。
  3. 点击不想要的那段，按 Delete。
  4. 不剪切也能缩短：拖动片段的开头或结尾即可。

小提示 在 音频 标签中，“剪掉静音”一键去掉旁白里所有的空白。

本教程的直达链接
  1. 把播放头放到文字要出现的位置。
  2. 打开 文字 标签，点击一种样式：文字就加到时间线上。
  3. 在右侧设置面板输入文字，再选字体、颜色和动画。
  4. 在预览中用鼠标移动文字，拖动角来调整大小。

小提示 DedCut 自带 200 多种文字样式和 100 种字体，可在任何地方免费使用。

本教程的直达链接
  1. 点击时间线上的片段将其选中。
  2. 特效 标签：鼠标悬停可预览特效动态，点击即可添加或移除。
  3. 滤镜 标签：点击滤镜改变片段的颜色；一个按钮即可应用到整个视频。
  4. 转场 标签：选择片段开头或结尾的转场，或与上一个片段的柔和淡化。

小提示 每个特效的强度在右侧面板中调节。

本教程的直达链接
  1. 打开 音频 标签。
  2. 在“音乐”中试听并添加免版权音乐（真实歌曲和 DedCut 制作的音乐）。
  3. 在视频合适的时刻加入音效（嗖、点击、掌声…）。
  4. 点击片段，在右侧面板调节音量，或将整条轨道静音。

小提示 这些音乐可以用在 YouTube、TikTok 等任何地方，没有版权风险。

本教程的直达链接
  1. 打开 字幕 标签。
  2. 选择精度：快速、均衡或精确。
  3. 第一次使用时，点击“下载模型”（只需下载一次）。
  4. 点击“生成字幕”：DedCut 会听你的视频，把字幕写到时间线上。
  5. 点击某条字幕，在右侧面板修改文字；改好样式后点“将此样式应用于全部”。

小提示 一切都在你的电脑上完成：你的声音和视频都不会发送到网上。

本教程的直达链接
  1. 打开「字幕」标签，点击「打开文本剪辑」（或右键点击片段 →「文本剪辑」）。
  2. 第一次使用时，DedCut 会在你的电脑上把视频里说的话全部写下来。
  3. 用鼠标选中文字后按 Del：视频会在同一位置被剪掉，后面的内容自动前移。
  4. 「去掉犹豫」一次去掉所有“嗯”，「缩短停顿」缩短较长的停顿。

小提示 字幕会跟着你的剪辑变化。Ctrl+Z 撤销。

本教程的直达链接
  1. 点击时间线的空白处（或按 Esc）：右侧出现 项目 面板。
  2. 在“一键画面比例”中选择“竖屏 9:16（TikTok、Shorts）”。
  3. 视频保留完整画面，后面垫一层模糊背景。
  4. 想换构图的话，在预览中移动或缩放每个片段。

小提示 同一个面板随时可以切回横屏。

本教程的直达链接
  1. 在剪辑中打开一个长视频（有字幕效果更好）。
  2. 点击「导出」→「自动短视频」。
  3. 选择时长和数量，然后「查找片段」：DedCut 会找出最精彩的片段。
  4. 留下喜欢的片段并生成短视频：每个都是竖屏项目，画面会跟随人物。

小提示 也可以对助手说：“做几个短视频”。

本教程的直达链接
  1. 把 2–4 个同时拍摄的视频放到时间线上（每人一台摄像机，各自带麦克风）。
  2. 按住 Ctrl+点击选中它们，右键 →「创建多机位」：DedCut 会按声音对齐。
  3. 在预览上方的「多机位」栏点击「自动」，选择节奏后点击「开始」。
  4. DedCut 会随时显示正在说话的人的画面。用 1–4 键切换镜头。

小提示 不会删除任何内容：Ctrl+Z 可全部撤销。

本教程的直达链接
  1. 把元素（文字、贴纸、箭头…）放到物体上，播放头放在这一段的开头。
  2. 右键点击元素 →「跟踪物体」：DedCut 会在视频里跟踪物体，元素随之移动。
  3. 要遮住车牌或人脸：右键点击视频 →「模糊移动的物体」，把区域放到物体上，再点「跟踪物体」。

小提示 物体消失时跟踪会在那里停止：稍后再重新开始。

本教程的直达链接
  1. 点击右上角的“导出”（或 Ctrl+E）。
  2. 起个名字，选择画质（最高 4K）和帧率。
  3. 开始导出，并选择文件保存位置。
  4. 也可以只导出声音（WAV 或 M4A）。

小提示 长时间导出时可以把 DedCut 最小化：它会在后台继续。

本教程的直达链接
  1. 先为视频生成字幕（「字幕」标签）。
  2. 点击「导出」→「YouTube 简介」。
  3. 选一个推荐的标题，修改简介和话题标签，然后「复制简介」。

小提示 章节（标记）会自动加入。有了 DedCut AI 大脑，一切都在你的电脑上完成。

本教程的直达链接

屏幕录制

录制屏幕、游戏、摄像头和你的声音。

  1. 打开 录制 空间。
  2. 在 来源 中点击“添加来源”，再点“屏幕 / 窗口”。
  3. “要共享什么？”窗口打开：选择一个屏幕或窗口，每个都有小预览。
  4. 勾选“共享电脑声音”可以录入游戏、音乐或 Discord 的声音（不含 DedCut 自己的声音）。
  5. 点击“开始录制”。要停止，再点一次或按 Ctrl+Shift+R。

小提示 视频会进入剪辑的媒体库，并保存在“视频\DedCut”文件夹。

本教程的直达链接
  1. 在 来源 中点击“添加来源”，再点“摄像头”：选择你的摄像头。
  2. 在预览中移动摄像头画面，拖动角调整大小；在它的设置里还能改成圆形。
  3. 在音频混音器中选择麦克风，边说话边调音量：音量条应保持在绿色区域。
  4. 麦克风滤镜可以减少背景噪音和呼吸声。

小提示 请戴耳机：否则音箱的声音会被麦克风再次录进去。

本教程的直达链接
  1. 在 场景 中，一个场景就是一种布局（例如“屏幕 + 摄像头”“马上回来”）。
  2. 用 + 按钮添加场景，再加入来源：屏幕、摄像头、图片、文字、聊天…
  3. 点击场景即可显示。录制或直播时，Ctrl+Shift+1 到 Ctrl+Shift+9 可以切换场景，游戏中也行。
  4. 拖动场景或来源可以调整顺序。

小提示 场景在 录制 和 直播 之间共用。

本教程的直达链接

直播

在 YouTube、Twitch、Facebook 或 Kick 上直播。

  1. 打开 直播 空间，准备好场景（屏幕、摄像头、麦克风）。
  2. 右侧 设置 标签：在“直播到哪里？”中选择平台（YouTube、Twitch、Facebook、Kick 或其他）。
  3. 从平台后台复制推流密钥，粘贴到“推流密钥”。
  4. 点击“开始直播”。会显示正在直播；再点一次即可停止。

小提示 推流密钥不会外泄：DedCut 把它加密保存在你的电脑上。

本教程的直达链接
  1. 在 设置 标签中点击“添加直播平台”，添加第二个平台及其密钥。
  2. 勾选要用的目标：直播同时推送到所有平台。
  3. 针对 TikTok 或 YouTube Shorts，打开“竖屏直播（TikTok、Shorts）”：DedCut 还会发送一个 9:16 版本。
  4. 检查网络：每个目标都需要占用一部分上传带宽。

小提示 先用一个平台测试你的网络。

本教程的直达链接
  1. 右侧 聊天 标签：连接你的频道来阅读消息。
  2. 添加“直播聊天”来源，把聊天显示在画面上，并在预览中摆好位置。
  3. 添加“提醒”来源，显示新关注和打赏。
  4. 投票、目标进度条和计数器也在“添加来源”里。

小提示 还可以用语音朗读聊天：在 工具 标签中设置。

本教程的直达链接
  1. 在 直播（或 录制）中点击“添加来源”，再点“叠加层”。
  2. 在右侧面板从 30 种样式中选择：摄像头边框、姓名条、等待画面、屏幕边框、提醒和氛围。把鼠标悬停在缩略图上可看到动画。
  3. 输入你的名字或消息，再选择两种颜色和速度。
  4. 在预览中用鼠标放置叠加层，拖动角可调整大小。

小提示 使用摄像头边框时，在来源列表中把“叠加层”放在摄像头上方。

本教程的直达链接
  1. 在电脑上打开 TikTok LIVE Producer 准备直播：TikTok 会给你服务器地址和密钥。
  2. 在「直播」中添加 TikTok 目标，粘贴「服务器地址」和「推流密钥」。
  3. 要竖屏直播，选择「把工作室切换为竖屏（TikTok 场景）」：TikTok 场景已经准备好。
  4. 从 DedCut 开始直播。

小提示 TikTok 每次直播的密钥都会变：每次重新复制，绝不要给别人看。

本教程的直达链接
  1. 点击或用 Ctrl+Shift+1 到 Ctrl+Shift+9 切换场景，在游戏里也可以。
  2. “同时录制”会在你的电脑上保留一份直播录像。
  3. Ctrl+Shift+M 在精彩时刻打个标记，剪辑时方便找到。
  4. 工作室模式先在预览中准备下一个场景，再切到直播画面。

小提示 直播结束后，录下的视频会进入剪辑，方便做切片。

本教程的直达链接

图像

封面、修图、抠图和绘画。

  1. 打开 图像 空间，点击“新建图像”。
  2. 选择“视频封面”预设（1280 × 720），然后点“创建”。
  3. 添加一张照片（拖进窗口），再用 文字 工具加上标题。
  4. 在图层效果里给文字加描边或阴影，远看也清楚。
  5. 文件 菜单 >“导出”：保存为 PNG 或 JPG。

小提示 每个元素都在独立的图层上：之后什么都能改。

本教程的直达链接
  1. 打开照片（拖进 图像 空间）。
  2. 图像 菜单 >“自动增强”一键校正光线和颜色。
  3. 滤镜 菜单：亮度、曲线、色阶、色相… 手动调整，并实时预览。
  4. 用裁剪工具裁剪，然后导出。

小提示 只要不覆盖保存，原图始终保持不变。

本教程的直达链接
  1. 在 图像 中打开照片。
  2. 选择 菜单 >“选择主体”：AI 会选中主要的人物或物体。
  3. 图层 菜单 >“移除背景（蒙版）”去掉背景（背景只是被蒙版遮住，可以找回）。
  4. 导出为 PNG 以保留透明。

小提示 抠图在你的电脑上计算：照片不会发送到任何地方。

本教程的直达链接
  1. 连接数位板（Wacom、XP-Pen、Huion…）或使用屏幕的触控笔。
  2. 编辑 菜单 >“手写笔和数位板”：调整压感，并在测试区试一试。
  3. 选择 画笔 工具：压力改变大小，倾斜改变角度，橡皮擦端可以擦除。
  4. 如果没有压感，请在数位板驱动中打开“Windows Ink”。

小提示 在新图层上画，改错时不会弄坏其他部分。

本教程的直达链接
  1. 剪辑：Ctrl+K →「添加二维码」，或在元素的「社交平台」类别中。
  2. 直播：「添加来源」→「二维码」。
  3. 图片：图层菜单 →「二维码」。
  4. 输入你的链接（频道、社交网络、网站）：观众用手机扫码即可。

小提示 保持浅色背景上的深色码点，并且足够大。

本教程的直达链接
  1. 在 图像 中右键图片：“将图片发送到剪辑”。图片会进入剪辑的时间线。
  2. 在 剪辑 中右键片段：“发送到图片”会在图像空间打开这一帧供你修改。

小提示 用视频里的一帧做封面时很方便。

本教程的直达链接

音乐

做节拍、写旋律、录人声并导出。

  1. 打开 音乐 空间，文件 菜单 >“新建项目”，选择“节拍”模板和速度（例如 120）。
  2. 点击鼓的片段，再打开下方的 步进 标签。
  3. 每一行是一种声音（底鼓、军鼓、踩镲…），每一格是一步：点击即可开关。
  4. 按 空格 试听。试试摇摆（swing），律动更有活力。
  5. 混音台 标签：调节每条轨道的音量。

小提示 DedCut 的鼓声由 DedCut 自己制作：哪里都能用，卖的音乐里也可以。

本教程的直达链接
  1. 在乐器轨道的空白处双击：会创建并打开一个片段。
  2. 钢琴卷帘 标签：点击网格放音符，拖动来移动，拉边缘来延长。
  3. 右键或 Delete 删除音符。
  4. 播放控制右边的键盘按钮能把电脑键盘变成钢琴。

小提示 在“乐器”标签中为轨道换个音色（钢琴、合成器、弦乐…）。

本教程的直达链接
  1. 插上麦克风，戴好耳机。
  2. 设置 菜单 > 声音：允许使用麦克风，并测量一次延迟。
  3. 轨道 菜单：添加音频轨道，选择输入，然后让轨道进入录音准备（圆形按钮）。
  4. 按 R 录音。开启循环后，每一遍都是一个录音条目（take），全部保留。
  5. 音频片段 标签：保留每个 take 最好的部分，再加上“清晰人声”效果链。

小提示 如果录音时 DedCut 关闭了，下次启动时可以恢复这段录音。

本教程的直达链接
  1. 在「音乐」中点击你的人声片段（单独的人声，上面没有音乐）。
  2. 打开「灵感与分析」（闪光图标按钮）。
  3. 在「人声演唱」中确认调，选择自然、强或机器人，然后「校正音准」。
  4. 要和声的话，勾选想要的声部，然后「添加和声」：每个声部各占一条音轨。

小提示 原声会保留（静音）：取消静音即可对比。

本教程的直达链接
  1. 完整听一遍：母带上的红灯应该一直不亮（没有削波）。
  2. 文件 菜单 >“导出音频”。
  3. 选择格式：无损的 WAV 或 FLAC，或更小的 M4A。
  4. 分轨（stems）会为每条轨道导出一个文件，起点全部对齐。
  5. 勾选“发送到剪辑”，就能在视频剪辑中找到你的音乐。

小提示 导出报告会列出每个文件的时长、响度（LUFS）和峰值。

本教程的直达链接

人工智能

替你剪辑的助手和 AI 工具，全部在你的电脑上运行。

  1. 在剪辑中点击右上角的气泡（“与替你剪辑的 AI 对话”）。

常见问题

最常见问题的解决办法。

  1. 有些独占全屏模式的游戏无法被捕获。
  2. 在游戏的图形设置中选择“窗口化全屏”（或“无边框窗口”）。
  3. 在 DedCut 中选择整个屏幕，而不是游戏窗口。

  1. 录像里没有游戏声音：在屏幕选择窗口中勾选“共享电脑声音”。
  2. 麦克风没声音：在音频混音器中选择它，并确认 Windows 允许 DedCut 使用麦克风。
  3. 用蓝牙耳机在“音乐”中播放没有声音：等几秒让耳机唤醒，或在声音设置中选择其他输出。
