# Site de DedCut — https://dedcut.com

Ce dépôt contient **seulement le site** de DedCut (pages, images et vidéos de présentation), servi par GitHub Pages.

**DedCut** est un logiciel de création **gratuit** pour Windows, fait par **ByKemi** : montage vidéo, enregistrement
d'écran, live, retouche photo et musique, avec un assistant IA. Tout se passe sur ton PC.

- Télécharger DedCut : https://github.com/Bykemi/DedCut-mises-a-jour/releases/latest
- Tutoriels : https://dedcut.com/tutos.html
- Signaler un bug : dans DedCut, clique sur la pastille « bêta » (ou Menu > Signaler un bug), ou écris à bugs@dedcut.com
