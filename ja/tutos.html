DedCut をステップごとに覚えよう

DedCut の各スペースの短くてかんたんなガイドです。カテゴリを選ぶか、やりたいことを検索してください。

はじめに

DedCut をインストールして基本を知ろう。

  1. このサイトで「ダウンロード」をクリック：DedCut-Installation.exe がダウンロード フォルダーに保存されます。
  2. ファイルを開きます。「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」をクリックします（DedCut は新しいので、Windows がまだ知らないだけです）。
  3. インストールは数秒で終わります。アカウントも管理者権限も不要です。
  4. DedCut がホーム画面で開きます：準備完了です。

ヒント その後のアップデートは自動です：新しいバージョンの準備ができると DedCut が知らせます。

このチュートリアルへの直接リンク
  1. ホーム画面でやりたいことを選ぶか、ウィンドウいちばん上のボタンでスペースを切り替えます。
  2. 編集：動画を編集（カット、テキスト、エフェクト、音楽、字幕、書き出し）。
  3. 録画：画面、ゲーム、Web カメラ、マイクを録画。
  4. ライブ：1 つまたは複数のプラットフォームでライブ配信。
  5. 画像：サムネイル作成、写真編集、お絵かき。
  6. 音楽：ドラムから書き出しまで、音楽を作る。

ヒント スペース同士はつながっています：曲や画像はワンクリックで編集に送れます。

このチュートリアルへの直接リンク
  1. Ctrl+Z で直前の操作を取り消し、Ctrl+Y でやり直し。何回でも取り消せます。
  2. Ctrl+S でプロジェクトを保存。DedCut は自動でも保存するので、何も失いません。
  3. 右上のキーボード ボタンですべてのショートカットを表示・変更できます。
  4. メニュー（左上）でプロジェクトの作成・読み込み・保存、設定 を開く、ガイド ツアーの再生ができます。
  5. パネルを移動したり、タイムラインを上か下に置いたり、パネルを別ウィンドウに切り離したりできます。

ヒント DedCut は 9 言語に対応：設定 の「言語」で選べます。

このチュートリアルへの直接リンク

動画編集

カット、テキスト、エフェクト、音楽を加えて書き出そう。

  1. 編集 スペースを開き、左の メディア タブを開きます。
  2. Windows エクスプローラーから動画・写真・音声をドラッグするか、エリアをクリックして選びます。
  3. 次に各素材を下のタイムラインにドラッグします：ここで動画を組み立てます。
  4. Space でプレビューを再生・一時停止します。

ヒント 重い 4K 動画？ DedCut が自動で軽いコピーを作るのでプレビューはなめらか。書き出しは元の画質のままです。

このチュートリアルへの直接リンク
  1. 再生ヘッド（縦の線）を好きな位置に置きます。
  2. タイムライン上のハサミをクリックするか S を押す：クリップが 2 つに分かれます。
  3. いらない部分をクリックして Delete を押します。
  4. カットせずに短くするには、クリップの始まりか終わりをドラッグします。

ヒント オーディオ タブの「無音をカット」で、ナレーションの間をワンクリックですべて削除できます。

このチュートリアルへの直接リンク
  1. テキストを出したい位置に再生ヘッドを置きます。
  2. テキスト タブを開いてスタイルをクリック：テキストがタイムラインに追加されます。
  3. 右の設定パネルに文字を入力し、フォント・色・アニメーションを選びます。
  4. プレビューでマウスを使ってテキストを動かし、角をドラッグしてサイズを変えます。

ヒント 200 以上のテキスト スタイルと 100 のフォントが付属。どこでも自由に使えます。

このチュートリアルへの直接リンク
  1. タイムラインのクリップをクリックして選びます。
  2. エフェクト タブ：エフェクトにマウスを乗せると動きを確認でき、クリックで追加・削除します。
  3. フィルター タブ：フィルターをクリックするとクリップの色が変わります。ボタン 1 つで動画全体に適用できます。
  4. トランジション タブ：クリップの最初か最後のトランジション、または前のクリップとのなめらかなフェードを選びます。

ヒント 各エフェクトの強さは右のパネルで調整します。

このチュートリアルへの直接リンク
  1. オーディオ タブを開きます。
  2. 「音楽」で著作権フリーの音楽（本物の楽曲と DedCut が作った音楽）を試聴して追加します。
  3. 効果音（シュッ、クリック、拍手…）を動画のちょうどいいタイミングに追加します。
  4. クリップをクリックして右のパネルで音量を調整するか、トラック全体をミュートします。

ヒント この音楽は YouTube、TikTok などどこでも、著作権の心配なく使えます。

このチュートリアルへの直接リンク
  1. 字幕 タブを開きます。
  2. 精度を選びます：速い、バランス、正確。
  3. 初回は「モデルをダウンロード」をクリックします（ダウンロードは 1 回だけ）。
  4. 「字幕を作成」をクリック：DedCut が動画を聞き取り、タイムラインに字幕を書き込みます。
  5. 字幕をクリックすると右のパネルで文字を直せます。スタイルを変えたら「このスタイルをすべてに適用」。

ヒント すべて PC 上で処理されます：声も動画もインターネットに送られません。

このチュートリアルへの直接リンク
  1. 「字幕」タブを開き、「テキスト編集を開く」をクリック（またはクリップを右クリック →「テキストで編集」）。
  2. 初回は、動画で話している内容を DedCut がすべてこのPCで書き出します。
  3. マウスで言葉を選んで Del キー：動画も同じ場所でカットされ、後ろが詰められます。
  4. 「言いよどみを削除」で「えー」をまとめて削除、「間を短くする」で長い間を縮めます。

ヒント 字幕もカットに合わせて直ります。Ctrl+Z で元に戻せます。

このチュートリアルへの直接リンク
  1. タイムラインの空いている場所をクリック（または Esc）：右に プロジェクト パネルが出ます。
  2. 「ワンクリックで形式変更」で「縦 9:16（TikTok、ショート）」を選びます。
  3. 動画は画面全体を保ったまま、後ろにぼかした背景が入ります。
  4. 別の構図にしたいときは、プレビューで各クリップを動かしたりサイズを変えたりします。

ヒント 同じパネルでいつでも横型に戻せます。

このチュートリアルへの直接リンク
  1. 長い動画を編集で開きます（字幕があるとさらに良くなります）。
  2. 「書き出し」→「自動ショート」をクリック。
  3. 長さと本数を選んで「場面を探す」：DedCut がいちばん盛り上がる場面を見つけます。
  4. 気に入った場面を残してショートを作成：それぞれ縦型のプロジェクトになり、人物を追う枠が付きます。

ヒント アシスタントに「ショートを作って」と頼むこともできます。

このチュートリアルへの直接リンク
  1. 同時に撮った動画を 2〜4 本タイムラインに置きます（一人に一台のカメラ、それぞれマイク付き）。
  2. Ctrl+クリックで選び、右クリック →「マルチカメラを作る」：DedCut が音で同期します。
  3. プレビュー上の「マルチカメラ」バーで「自動」をクリックし、テンポを選んで「開始」。
  4. DedCut が話している人のカメラを映します。1〜4 キーで画を変えられます。

ヒント 何も削除されません。Ctrl+Z ですべて元に戻せます。

このチュートリアルへの直接リンク
  1. 要素（テキスト、ステッカー、矢印など）を物体に重ね、再生位置をその場面の最初に合わせます。
  2. 要素を右クリック →「物体を追跡」：DedCut が動画の中の物体を追い、要素がついていきます。
  3. ナンバーや顔を隠すには、動画を右クリック →「動くものをぼかす」、ゾーンを物体に重ねて「物体を追跡」。

ヒント 物体が見えなくなると追跡はそこで止まります。少し先からやり直してください。

このチュートリアルへの直接リンク
  1. 右上の「書き出し」をクリック（または Ctrl+E）。
  2. 名前を付け、画質（最大 4K）とフレームレートを選びます。
  3. 書き出しを始め、ファイルの保存先を選びます。
  4. 音声だけ（WAV または M4A）を書き出すこともできます。

ヒント 長い書き出しの間は DedCut を最小化しても大丈夫：バックグラウンドで続きます。

このチュートリアルへの直接リンク
  1. 先に動画の字幕を作ります（「字幕」タブ）。
  2. 「書き出し」→「YouTube の説明文」をクリック。
  3. 提案されたタイトルを選び、説明文とハッシュタグを整えて「説明文をコピー」。

ヒント チャプター（マーカー）は自動で入ります。DedCut AI の頭脳があれば、すべてこのPCで書かれます。

このチュートリアルへの直接リンク

画面録画

画面、ゲーム、Web カメラ、声を録画しよう。

  1. 録画 スペースを開きます。
  2. ソース で「ソースを追加」→「画面／ウィンドウ」をクリックします。
  3. 「何を共有しますか？」ウィンドウが開きます：小さなプレビュー付きの画面かウィンドウを選びます。
  4. 「PC の音を共有」にチェックすると、ゲーム・音楽・Discord の音が入ります（DedCut 自身の音は入りません）。
  5. 「録画を開始」をクリック。止めるにはもう一度クリックするか Ctrl+Shift+R。

ヒント 動画は編集のメディアと「ビデオ\DedCut」フォルダーに保存されます。

このチュートリアルへの直接リンク
  1. ソース で「ソースを追加」→「Webカメラ」をクリックし、カメラを選びます。
  2. プレビューで Web カメラを動かし、角をドラッグしてサイズを変えます。設定で丸い形にもできます。
  3. オーディオ ミキサーでマイクを選び、話しながら音量を調整します：バーは緑の範囲に収めましょう。
  4. マイク フィルターで背景ノイズや息の音を減らせます。

ヒント ヘッドホンを使いましょう：スピーカーの音がマイクに戻ってしまいます。

このチュートリアルへの直接リンク
  1. シーン のシーンはレイアウトのことです（例：「画面 + Web カメラ」「すぐ戻ります」）。
  2. + ボタンでシーンを追加し、ソース（画面、Web カメラ、画像、テキスト、チャット…）を入れます。
  3. シーンをクリックすると表示されます。録画中やライブ中は Ctrl+Shift+1〜Ctrl+Shift+9 でゲーム中でもシーンを切り替えられます。
  4. シーンやソースをドラッグして順番を変えます。

ヒント シーンは 録画 と ライブ で共通です。

このチュートリアルへの直接リンク

ライブ

YouTube、Twitch、Facebook、Kick でライブ配信しよう。

  1. ライブ スペースを開き、シーン（画面、Web カメラ、マイク）を準備します。
  2. 右の 設定 タブ：「配信先」でプラットフォーム（YouTube、Twitch、Facebook、Kick など）を選びます。
  3. プラットフォームの管理画面からストリーム キーをコピーし、「ストリームキー」に貼り付けます。
  4. 「配信開始」をクリック。配信中であることが表示されます。止めるにはもう一度クリック。

ヒント ストリーム キーは秘密のまま：DedCut が PC 上に暗号化して保存します。

このチュートリアルへの直接リンク
  1. 設定 タブで「配信先を追加」をクリックし、2 つ目のプラットフォームとキーを追加します。
  2. 使う配信先にチェック：ライブがすべてに同時に流れます。
  3. TikTok や YouTube Shorts には「縦型ライブ（TikTok・ショート）」をオンに：DedCut が 9:16 版も送ります。
  4. 回線を確認しましょう：配信先ごとにアップロード速度が必要です。

ヒント まずは 1 つのプラットフォームで回線を試しましょう。

このチュートリアルへの直接リンク
  1. 右の チャット タブ：チャンネルを接続してメッセージを読みます。
  2. 「配信チャット」ソースを追加して画面にチャットを表示し、プレビューで配置します。
  3. 「アラート」ソースを追加して新しいフォロワーや投げ銭を表示します。
  4. アンケート、目標バー、カウンターも「ソースを追加」にあります。

ヒント チャットを音声で読み上げることもできます：ツール タブで設定。

このチュートリアルへの直接リンク
  1. ライブ（または 録画）で「ソースを追加」→「オーバーレイ」をクリックします。
  2. 右のパネルで 30 のスタイルから選びます：Webカメラ枠、名前テロップ、待機画面、画面フレーム、お知らせ、演出。サムネイルにマウスを乗せると動きが見られます。
  3. 名前やメッセージを入力し、2 つの色と速さを選びます。
  4. プレビュー上でマウスでオーバーレイを配置し、角をドラッグして大きさを変えます。

ヒント Webカメラ枠は、ソース一覧で「オーバーレイ」をWebカメラより上に置きます。

このチュートリアルへの直接リンク
  1. パソコンで TikTok LIVE Producer を開いて準備します。サーバーのアドレスとキーが表示されます。
  2. 「ライブ」で配信先 TikTok を追加し、「サーバーのアドレス」と「ストリームキー」を貼り付けます。
  3. 縦型で配信するなら「スタジオを縦にする（TikTok 用シーン）」：TikTok 用のシーンが用意されています。
  4. DedCut から配信を開始します。

ヒント TikTok のキーは配信ごとに変わります。毎回コピーし直し、絶対に見せないでください。

このチュートリアルへの直接リンク
  1. クリック、または Ctrl+Shift+1〜Ctrl+Shift+9 でシーンを切り替え。ゲーム中でも使えます。
  2. 「同時に録画」でライブのコピーを PC に残せます。
  3. Ctrl+Shift+M でいい場面にマーカーを付け、編集で見つけやすくします。
  4. スタジオ モードでは、次のシーンをプレビューで準備してから配信に出せます。

ヒント ライブ後、録画した動画は編集に入るので切り抜きが作れます。

このチュートリアルへの直接リンク

画像

サムネイル、写真編集、切り抜き、お絵かき。

  1. 画像 スペースを開き、「新規画像」をクリックします。
  2. 「動画サムネイル」（1280 × 720）を選んで「作成」。
  3. 写真を追加（ウィンドウにドラッグ）し、テキスト ツールでタイトルを入れます。
  4. 遠くからでも読めるよう、レイヤー効果でテキストに縁取りや影を付けます。
  5. ファイル メニュー ＞「書き出し」：PNG か JPG で保存します。

ヒント 各要素は別々のレイヤーにあるので、あとから何でも変えられます。

このチュートリアルへの直接リンク
  1. 写真を開きます（画像 スペースにドラッグ）。
  2. 画像 メニュー ＞「自動補正」でワンクリックで明るさと色を補正。
  3. フィルター メニュー：明るさ、トーンカーブ、レベル補正、色相… をライブ プレビューで手動調整。
  4. 切り抜きツールでトリミングしてから書き出します。

ヒント 上書き保存しない限り、元の写真はそのまま残ります。

このチュートリアルへの直接リンク
  1. 画像 で写真を開きます。
  2. 選択範囲 メニュー ＞「被写体を選択」：AI がメインの人や物を選択します。
  3. レイヤー メニュー ＞「背景を削除（マスク）」で背景を消します（マスクで隠すだけなので元に戻せます）。
  4. 透明部分を残すには PNG で書き出します。

ヒント 切り抜きは PC 上で計算されます：写真はどこにも送られません。

このチュートリアルへの直接リンク
  1. ペンタブレット（Wacom、XP-Pen、Huion…）をつなぐか、画面のペンを使います。
  2. 編集 メニュー ＞「ペンとペンタブレット」：筆圧を調整し、テスト エリアで試します。
  3. ブラシ ツールを選択：筆圧でサイズ、傾きで角度が変わり、消しゴム側で消せます。
  4. 筆圧が効かない場合は、タブレットのソフトで「Windows Ink」をオンにします。

ヒント 新しいレイヤーに描けば、ほかを崩さずに修正できます。

このチュートリアルへの直接リンク
  1. 編集：Ctrl+K →「QRコードを追加」、または要素の SNS カテゴリ。
  2. ライブ：「ソースを追加」→「QRコード」。
  3. 画像：レイヤーメニュー →「QRコード」。
  4. リンク（チャンネル、SNS、サイト）を入力：視聴者はスマホで読み取ります。

ヒント 明るい背景に暗いドットで、十分な大きさにしてください。

このチュートリアルへの直接リンク
  1. 画像 で画像を右クリック：「画像を編集へ送る」。編集のタイムラインに入ります。
  2. 編集 でクリップを右クリック：「画像へ送る」でそのフレームを画像スペースで開いて補正できます。

ヒント 動画のワンシーンからサムネイルを作るのに便利です。

このチュートリアルへの直接リンク

音楽

ビートとメロディを作り、声を録音して書き出そう。

  1. 音楽 スペースを開き、ファイル メニュー ＞「新規プロジェクト」で「ビート」テンプレートとテンポ（例：120）を選びます。
  2. ドラムのクリップをクリックし、下の ステップ タブを開きます。
  3. 各行が音（キック、スネア、ハイハット…）、各マスが 1 ステップ：クリックでオン・オフ。
  4. Space で再生。スウィングを試すとノリが良くなります。
  5. ミキサー タブ：各トラックの音量を調整します。

ヒント DedCut のドラム音は DedCut 製：販売する音楽でも、どこでも使えます。

このチュートリアルへの直接リンク
  1. 楽器トラックの空いている場所をダブルクリック：クリップが作られて開きます。
  2. ピアノロール タブ：グリッドをクリックでノートを置き、ドラッグで移動、端を引っぱって長くします。
  3. 右クリックか Delete でノートを削除。
  4. 再生ボタンの右にあるキーボード ボタンで、PC のキーボードがピアノになります。

ヒント 「楽器」タブでトラックの音色（ピアノ、シンセ、ストリングス…）を変えられます。

このチュートリアルへの直接リンク
  1. マイクをつなぎ、ヘッドホンを付けます。
  2. 設定 メニュー ＞ サウンド：マイクを許可し、一度だけ遅延を測ります。
  3. トラック メニュー：オーディオ トラックを追加して入力を選び、トラックを録音待機に（丸いボタン）。
  4. R で録音。ループをオンにすると毎回がテイクになり、すべて残ります。
  5. オーディオクリップ タブ：各テイクのいいところを残し、「クリアな声」エフェクト チェーンを追加します。

ヒント 録音中に DedCut が閉じても、次の起動時にテイクを復元できます。

このチュートリアルへの直接リンク
  1. 「音楽」で歌声のクリップをクリック（声だけの素材、上に音楽なし）。
  2. 「アイデアと解析」を開きます（きらめきのボタン）。
  3. 「歌声」でキーを確認し、自然・強め・ロボットを選んで「音程を補正」。
  4. コーラスは欲しい声にチェックを入れて「コーラスを追加」：声ごとにトラックが作られます。

ヒント 元の声はミュートして残ります。比べるときはミュートを解除してください。

このチュートリアルへの直接リンク
  1. 曲を最後まで聴きます：マスターの赤いランプが消えたままなら OK（音割れなし）。
  2. ファイル メニュー ＞「オーディオを書き出す」。
  3. 形式を選びます：ロスレスの WAV や FLAC、または軽い M4A。
  4. ステムはトラックごとに 1 ファイル、すべて同じ位置から始まります。
  5. 「編集へ送る」にチェックすると、動画編集でその音楽を使えます。

ヒント 書き出しレポートで各ファイルの長さ、ラウドネス（LUFS）、ピークがわかります。

人工知能

あなたの代わりに編集するアシスタントと AI ツール、すべて PC 上で。

  1. 編集で、右上の吹き出し（「代わりに編集してくれる AI と会話」）をクリックします。
  2. やりたいことを書きます：「無音をカットして字幕を付けて」「動画を縦にして」…
  3. アシスタントが DedCut の中で直接編集し、ボタン 1 つで全部元に戻せます。
  4. DedCut についての質問もできます。

ヒント DedCut AI は PC 上で動き、無料でアカウントも不要です。

このチュートリアルへの直接リンク
  1. 編集で AI動画 タブを開きます。
  2. 動かしたい画像を追加するか、見たいものを文章で書きます。

  4. 初回は AI モデルをダウンロードします。そのあとは PC 上ですべて処理されます。

ヒント 新しめのグラフィック カードだと作成がかなり速くなります。

  1. 人が映っているクリップを選びます。
  2. エフェクト タブの「人物」カテゴリ：背景ぼかし、背景モノクロ、縁取り、ネオン、オーラ…

よくある問題

よくあるトラブルの解決方法。

  1. 排他的フルスクリーンのゲームは録画できないことがあります。
  2. ゲームのグラフィック設定で「ボーダーレス ウィンドウ」（または「ウィンドウ フルスクリーン」）を選びます。
  3. DedCut では、ゲームのウィンドウではなく画面全体を選びます。

  1. 録画にゲームの音が入らない：画面選択ウィンドウで「PC の音を共有」にチェックします。
  2. マイクが無音：オーディオ ミキサーでマイクを選び、Windows が DedCut にマイクの使用を許可しているか確認します。
  3. Bluetooth ヘッドホンで「音楽」の再生音が出ない：起動するまで数秒待つか、サウンド設定で別の出力を選びます。
