DedCut을 단계별로 배우기

DedCut의 모든 공간을 위한 짧고 쉬운 안내입니다. 카테고리를 고르거나 하고 싶은 일을 검색하세요.

시작하기

DedCut을 설치하고 기본을 알아보세요.

  1. 이 사이트에서 다운로드를 클릭하세요. DedCut-Installation.exe 파일이 다운로드 폴더에 저장됩니다.
  2. 파일을 여세요. "Windows의 PC 보호" 창이 뜨면 "추가 정보", "실행"을 차례로 클릭하세요 (DedCut은 새 프로그램이라 Windows가 아직 모를 뿐입니다).
  3. 설치는 몇 초면 끝나며, 계정도 관리자 권한도 필요 없습니다.
  4. DedCut이 홈 화면으로 열립니다. 준비 완료!

팁 이후 업데이트는 자동입니다. 새 버전이 준비되면 DedCut이 알려 줍니다.

이 튜토리얼 바로가기
  1. 홈 화면에서 하고 싶은 일을 고르거나, 창 맨 위의 버튼으로 공간을 바꾸세요.
  2. 편집: 동영상 편집 (컷, 텍스트, 효과, 음악, 자막, 내보내기).
  3. 녹화: 화면, 게임, 웹캠, 마이크 녹화.
  4. 라이브: 하나 또는 여러 플랫폼에서 라이브 방송.
  5. 이미지: 썸네일 만들기, 사진 보정, 그림 그리기.
  6. 음악: 드럼부터 내보내기까지 음악 만들기.

팁 공간끼리 연결되어 있어 노래나 이미지를 클릭 한 번으로 편집에 보낼 수 있습니다.

이 튜토리얼 바로가기
  1. Ctrl+Z는 마지막 작업 취소, Ctrl+Y는 다시 실행입니다. 원하는 만큼 취소할 수 있습니다.
  2. Ctrl+S로 프로젝트를 저장합니다. DedCut은 자동으로도 저장해서 아무것도 잃지 않습니다.
  3. 오른쪽 위 키보드 버튼으로 모든 단축키를 보고 바꿀 수 있습니다.
  4. 메뉴(왼쪽 위)에서 프로젝트를 만들고, 열고, 저장하며, 설정을 열고 가이드 투어를 다시 볼 수 있습니다.
  5. 패널을 옮기고, 타임라인을 위나 아래에 두고, 패널을 별도 창으로 분리할 수 있습니다.

팁 DedCut은 9개 언어를 지원합니다. 설정의 언어 항목에서 고르세요.

이 튜토리얼 바로가기

동영상 편집

자르고, 텍스트·효과·음악을 넣고, 내보내세요.

  1. 편집 공간을 열고 왼쪽의 미디어 탭을 여세요.
  2. Windows 탐색기에서 동영상, 사진, 소리를 끌어오거나 영역을 클릭해 고르세요.
  3. 그런 다음 각 항목을 아래 타임라인으로 끄세요. 여기서 동영상이 만들어집니다.
  4. Space로 미리보기를 재생하거나 멈춥니다.

팁 무거운 4K 동영상도 걱정 마세요. DedCut이 가벼운 사본을 알아서 만들어 미리보기가 부드럽고, 내보내기는 원본 화질 그대로입니다.

이 튜토리얼 바로가기
  1. 재생 헤드(세로선)를 원하는 위치에 두세요.
  2. 타임라인 위의 가위를 클릭하거나 S를 누르면 클립이 둘로 나뉩니다.
  3. 필요 없는 부분을 클릭하고 Delete를 누르세요.
  4. 자르지 않고 줄이려면 클립의 시작이나 끝을 끄세요.

팁 오디오 탭의 "무음 자르기"는 내레이션의 빈 구간을 클릭 한 번으로 모두 없앱니다.

이 튜토리얼 바로가기
  1. 텍스트가 나올 위치에 재생 헤드를 두세요.
  2. 텍스트 탭을 열고 스타일을 클릭하면 타임라인에 텍스트가 추가됩니다.
  3. 오른쪽 설정 패널에 글자를 입력하고 글꼴, 색, 애니메이션을 고르세요.
  4. 미리보기에서 마우스로 텍스트를 옮기고 모서리를 끌어 크기를 바꾸세요.

팁 200개가 넘는 텍스트 스타일과 100개의 글꼴이 들어 있으며, 어디서나 자유롭게 쓸 수 있습니다.

이 튜토리얼 바로가기
  1. 타임라인의 클립을 클릭해 선택하세요.
  2. 효과 탭: 효과에 마우스를 올리면 움직임을 볼 수 있고, 클릭하면 추가하거나 뺍니다.
  3. 필터 탭: 필터를 클릭하면 클립의 색이 바뀌고, 버튼 하나로 동영상 전체에 적용됩니다.
  4. 전환 탭: 클립 시작이나 끝의 전환, 또는 앞 클립과의 부드러운 페이드를 고르세요.

팁 각 효과의 세기는 오른쪽 패널에서 조절합니다.

이 튜토리얼 바로가기
  1. 오디오 탭을 여세요.
  2. "음악"에서 저작권 걱정 없는 음악(실제 노래와 DedCut이 만든 음악)을 듣고 추가하세요.
  3. 효과음(휙, 클릭, 박수…)을 동영상의 알맞은 순간에 넣으세요.
  4. 클립을 클릭해 오른쪽 패널에서 볼륨을 조절하거나, 트랙 전체를 음소거하세요.

팁 이 음악은 YouTube, TikTok 등 어디서나 저작권 걱정 없이 쓸 수 있습니다.

이 튜토리얼 바로가기
  1. 자막 탭을 여세요.
  2. 정확도를 고르세요: 빠름, 균형, 정확.
  3. 처음에는 "모델 다운로드"를 클릭하세요 (한 번만 다운로드).
  4. "자막 만들기"를 클릭하면 DedCut이 동영상을 듣고 타임라인에 자막을 씁니다.
  5. 자막을 클릭해 오른쪽 패널에서 글자를 고치고, 스타일을 바꾼 뒤 "이 스타일을 모두에 적용"를 누르세요.

팁 모든 처리는 내 PC에서 이루어집니다. 목소리도 동영상도 인터넷으로 보내지지 않습니다.

이 튜토리얼 바로가기
  1. 자막 탭을 열고 "텍스트 편집 열기"을 누르세요 (또는 클립을 오른쪽 클릭 → "텍스트로 편집").
  2. 처음 한 번, DedCut이 영상에서 말한 내용을 모두 이 PC에서 받아 적어요.
  3. 마우스로 단어를 선택하고 Del 키를 누르세요: 영상도 같은 곳이 잘리고 뒤가 당겨져요.
  4. "머뭇거림 없애기"는 "음…"을 한 번에 없애고, "공백 줄이기"는 긴 멈춤을 줄여요.

팁 자막도 자른 대로 따라와요. Ctrl+Z로 되돌려요.

이 튜토리얼 바로가기
  1. 타임라인의 빈 곳을 클릭하세요 (또는 Esc). 오른쪽에 프로젝트 패널이 나타납니다.
  2. "원클릭 형식"에서 "세로 9:16 (TikTok, Shorts)"를 고르세요.
  3. 동영상은 화면 전체를 그대로 유지하고, 뒤에는 흐린 배경이 깔립니다.
  4. 다른 구도를 원하면 미리보기에서 각 클립을 옮기거나 크기를 바꾸세요.

팁 같은 패널에서 언제든 가로로 되돌릴 수 있습니다.

이 튜토리얼 바로가기
  1. 긴 영상을 편집에서 여세요 (자막이 있으면 더 좋아요).
  2. "내보내기" → "자동 쇼츠"을 누르세요.
  3. 길이와 개수를 고르고 "순간 찾기": DedCut이 가장 생생한 순간을 찾아요.
  4. 마음에 드는 순간을 남기고 쇼츠를 만드세요: 각각 세로 프로젝트가 되고, 화면이 사람을 따라가요.

팁 어시스턴트에게 "쇼츠 만들어 줘"라고 해도 돼요.

이 튜토리얼 바로가기
  1. 동시에 찍은 영상 2~4개를 타임라인에 놓으세요 (한 사람에 카메라 하나, 각자 마이크).
  2. Ctrl+클릭으로 선택하고 오른쪽 클릭 → "멀티캠 만들기": DedCut이 소리로 맞춰요.
  3. 미리보기 위 "멀티캠" 막대에서 "자동"을 누르고 리듬을 고른 뒤 "시작".
  4. DedCut이 매 순간 말하는 사람의 카메라를 보여줘요. 1~4 키로 장면을 바꿀 수 있어요.

팁 아무것도 지워지지 않아요. Ctrl+Z로 모두 되돌려요.

이 튜토리얼 바로가기
  1. 요소(텍스트, 스티커, 화살표…)를 물체 위에 놓고, 재생 위치를 그 장면의 처음에 두세요.
  2. 요소를 오른쪽 클릭 → "물체 추적": DedCut이 영상 속 물체를 따라가고 요소도 따라가요.
  3. 번호판이나 얼굴을 가리려면 영상을 오른쪽 클릭 → "움직이는 것 흐리게 하기", 영역을 물체에 놓고 "물체 추적".

팁 물체가 사라지면 추적이 거기서 멈춰요. 조금 뒤에서 다시 시작하세요.

이 튜토리얼 바로가기
  1. 오른쪽 위의 "내보내기"를 클릭하세요 (또는 Ctrl+E).
  2. 이름을 정하고 화질(최대 4K)과 프레임 레이트를 고르세요.
  3. 내보내기를 시작하고 파일을 저장할 곳을 고르세요.
  4. 소리만 (WAV 또는 M4A) 내보낼 수도 있습니다.

팁 긴 내보내기 중에는 DedCut을 최소화해도 됩니다. 백그라운드에서 계속 진행됩니다.

이 튜토리얼 바로가기
  1. 먼저 영상의 자막을 만드세요 (자막 탭).
  2. "내보내기" → "유튜브 설명"을 누르세요.
  3. 제안된 제목 중 하나를 고르고 설명과 해시태그를 다듬은 뒤 "설명 복사".

팁 챕터(마커)는 자동으로 들어가요. DedCut AI 두뇌가 있으면 모두 이 PC에서 써요.

이 튜토리얼 바로가기

화면 녹화

화면, 게임, 웹캠, 목소리를 녹화하세요.

  1. 녹화 공간을 여세요.
  2. 소스에서 "소스 추가", "화면 / 창"을 차례로 클릭하세요.
  3. "무엇을 공유할까요?" 창이 열립니다. 작은 미리보기와 함께 보이는 화면이나 창을 고르세요.
  4. "PC 소리 공유"에 체크하면 게임, 음악, Discord 소리가 함께 녹음됩니다 (DedCut 자체 소리는 빠집니다).
  5. "녹화 시작"를 클릭하세요. 멈추려면 다시 클릭하거나 Ctrl+Shift+R을 누르세요.

팁 동영상은 편집 미디어와 동영상\DedCut 폴더에 저장됩니다.

이 튜토리얼 바로가기
  1. 소스에서 "소스 추가", "웹캠"을 클릭하고 카메라를 고르세요.
  2. 미리보기에서 웹캠을 옮기고 모서리를 끌어 크기를 바꾸세요. 설정에서 둥근 모양도 고를 수 있습니다.
  3. 오디오 믹서에서 마이크를 고르고 말하면서 볼륨을 맞추세요. 막대가 초록색 안에 있어야 합니다.
  4. 마이크 필터로 배경 소음과 숨소리를 줄일 수 있습니다.

팁 헤드폰을 쓰세요. 아니면 스피커 소리가 마이크로 다시 들어갑니다.

이 튜토리얼 바로가기
  1. 장면에서 장면은 화면 구성입니다 (예: "화면 + 웹캠", "잠시 후 돌아옵니다").
  2. + 버튼으로 장면을 추가하고 소스(화면, 웹캠, 이미지, 텍스트, 채팅…)를 넣으세요.
  3. 장면을 클릭하면 표시됩니다. 녹화나 라이브 중에는 Ctrl+Shift+1~Ctrl+Shift+9로 게임 중에도 장면을 바꿀 수 있습니다.
  4. 장면이나 소스를 끌어서 순서를 바꾸세요.

팁 장면은 녹화과 라이브에서 함께 씁니다.

이 튜토리얼 바로가기

라이브

YouTube, Twitch, Facebook, Kick에서 라이브 방송하세요.

  1. 라이브 공간을 열고 장면(화면, 웹캠, 마이크)을 준비하세요.
  2. 오른쪽 설정 탭: "어디로 방송할까요?"에서 플랫폼(YouTube, Twitch, Facebook, Kick 등)을 고르세요.
  3. 플랫폼 대시보드에서 스트림 키를 복사해 "스트림 키"에 붙여 넣으세요.
  4. "방송 시작"를 클릭하세요. 방송 중 표시가 나타나며, 다시 클릭하면 멈춥니다.

팁 스트림 키는 비밀로 유지됩니다. DedCut이 내 PC에 암호화해 보관합니다.

이 튜토리얼 바로가기
  1. 설정 탭에서 "방송 대상 추가"를 클릭하고 두 번째 플랫폼과 키를 추가하세요.
  2. 사용할 목적지에 체크하면 라이브가 모든 곳에 동시에 나갑니다.
  3. TikTok이나 YouTube Shorts용으로 "세로 라이브(TikTok, 쇼츠)"을 켜면 DedCut이 9:16 버전도 보냅니다.
  4. 인터넷 연결을 확인하세요. 목적지마다 업로드 속도가 필요합니다.

팁 먼저 플랫폼 하나로 연결을 시험해 보세요.

이 튜토리얼 바로가기
  1. 오른쪽 채팅 탭: 채널을 연결해 메시지를 읽으세요.
  2. "방송 채팅" 소스를 추가해 화면에 채팅을 띄우고 미리보기에서 위치를 잡으세요.
  3. "알림" 소스를 추가해 새 팔로워와 후원을 표시하세요.
  4. 투표, 목표 바, 카운터도 "소스 추가"에 있습니다.

팁 채팅을 음성으로 읽어 줄 수도 있습니다. 도구 탭에서 설정하세요.

이 튜토리얼 바로가기
  1. 라이브(또는 녹화)에서 "소스 추가", "오버레이"를 차례로 클릭하세요.
  2. 오른쪽 패널에서 30가지 스타일 중 하나를 고르세요: 웹캠 프레임, 이름 자막바, 대기 화면, 화면 테두리, 알림 배지, 분위기. 썸네일에 마우스를 올리면 움직임을 볼 수 있어요.
  3. 이름이나 메시지를 쓰고 두 가지 색과 속도를 고르세요.
  4. 미리보기에서 마우스로 오버레이를 배치하고 모서리를 끌어 크기를 바꾸세요.

팁 웹캠 프레임은 소스 목록에서 "오버레이"를 웹캠보다 위에 두세요.
